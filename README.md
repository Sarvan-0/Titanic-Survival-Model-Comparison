# Titanic Survival Model Comparison

## Overview
A machine learning project that predicts passenger survival on the Titanic using multiple classification algorithms and compares their performance using evaluation metrics.

## Models Implemented
- Logistic Regression
- K-Nearest Neighbors (KNN)
- Gaussian Naive Bayes
- Decision Tree
- Support Vector Machine (SVM)

## Technologies Used
- Python
- Pandas
- NumPy
- Matplotlib
- Seaborn
- Scikit-learn
- Jupyter Notebook

## Evaluation Metrics
The models are evaluated using:
- Accuracy
- Precision
- Recall
- F1-score

A comparison table is used to identify the best-performing model based on its F1-score, with accuracy used to break ties.

## Project Structure
- `Titanic_Survival_Model_Comparison.ipynb` — Data analysis, preprocessing, model training, evaluation, and comparison.

## How to Run
1. Clone this repository.
2. Install the required libraries:
   ```bash
   pip install pandas numpy matplotlib seaborn scikit-learn jupyter
   ```
3. Open the notebook in Jupyter Notebook or VS Code.
4. Run the cells from top to bottom.

## Results
The notebook generates a performance comparison table and identifies the model with the highest F1-score. See the notebook for the actual results.
